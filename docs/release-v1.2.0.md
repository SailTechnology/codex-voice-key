新增全局语音输入、讲话时的文字预览，以及更活泼的水跃鱼胶囊。

- 开启 `AllApplications: true` 后，可在微信、浏览器、文档等支持粘贴的输入框使用同一语音键。先点击输入位置，再按住讲话，松开填入，不自动发送。安装器和 skill 部署脚本均支持 `-AllApplications`；未指定时保留已有范围，新安装仍默认只在配置的目标应用生效。
- `LivePreview: true` 时，模型就绪后约每 2.2 秒尝试刷新一次胶囊里的文字。采用分段预览，处理最近至多 12 秒的声音；松开后校正并填入完整录音。首次讲话仍需等待模型加载，预览文字可能修正。可关闭此选项以减少识别工作。
- 预览和最终识别共用一个后台模型，模型忙时跳过预览。开机仍只启动轻量语音桥，默认空闲 60 秒释放模型和显存。
- 保留白色平滑胶囊与像素博士帽水跃鱼。角色轻轻摆动，波形与呼吸环跟随真实麦克风音量；新增 26 句聆听、整理、成功与重试短句，以及录音计时。胶囊位于开始录音的应用所在屏幕任务栏上方。
- 粘贴前检查原窗口与可检测到的原生输入控件，并等待快捷键修饰键松开；切换位置时留在剪贴板。剪贴板失败会明确提示。
