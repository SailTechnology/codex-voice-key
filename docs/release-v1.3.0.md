讲话时自动静音外放，松开后恢复，减少视频、音乐或自动续播声音进入麦克风造成的串扰。

- 默认开启 `MuteOutputWhileRecording`，录音前静音当前活动的输出设备，停止录音后就恢复，无需等待模型转写。
- 保留每个设备原本的静音状态，不修改音量数值或麦克风设置。原本已静音的设备仍保持静音。视频、音乐会继续无声播放，播放进度不会暂停。
- 临时独立进程负责静音恢复；语音桥意外退出时也会恢复。恢复状态记录留在本机，启动时检查上次未完成的恢复。断开的设备保留待恢复记录。
- 升级、改键重启和卸载会先等待音频守护进程恢复声音。需要关闭功能时，把配置中的 `MuteOutputWhileRecording` 设为 `false`。
- 保留全局输入、文字预览、现有按键、白色水跃鱼胶囊和默认空闲 60 秒释放模型的行为。
